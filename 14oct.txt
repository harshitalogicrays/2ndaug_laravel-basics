controller types - 
1. basic - php artisan make:controller ProvisionServer
Route::post('/server', [ProvisionServer::class,'fun']);

2. single action - php artisan make:controller ProvisionServer --invokable
Route::post('/server', ProvisionServer::class);

3. resource controller - 
php artisan make:controller PhotoController --resource
Route::resource('photos', PhotoController::class);


Verb            URI	                Action	    Route
GET	      /photos	                index	photos.index
GET         /photos/create	          create	photos.create
POST	      /photos	                store   photos.store
GET	      /photos/{photo}	       show	   photos.show
GET	      /photos/{photo}/edit	    edit	   photos.edit
PUT/PATCH	/photos/{photo} 	       update	photos.update
DELETE	   /photos/{photo}	      destroy	photos.destroy

1. global -> run middleware file during every HTTP request.
2. group -> bunch of middlewares
3. route ->  specific route
